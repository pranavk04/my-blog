Definition

The tangent bundle is a special case of the more general concept of a vector bundle. Roughly, a real vector bundle of rank \(r\) over \(M\) is a family of \(r\)-dimensional real vector spaces parameterized by \(M\):

Definition 5.3.1.1.

A real smooth vector bundle of rank \(r\) over \(M\) consists of

  1. a smooth manifold \(E\) called the total space, and
  2. a smooth surjective map \(\pi: E \to M\).

such that the following hold:

  1. local trivializations: there is an open cover \(\{U_\alpha: \alpha \in I\}\) of \(M\) (here \(U_\alpha\) are just opens, not necessarily coordinate patches) and smooth diffeomorphisms \(h_\alpha: \pi^{-1}(U_\alpha) \to U_\alpha \times \mathbb R^r\) such that \(\pi_\alpha = \mathrm{pr}_1 \circ h_\alpha\), where \(\pi_\alpha\) is restriction of \(\pi\) to \(\pi^{-1}(U_\alpha)\). The \(h_\alpha\) are the local trivializations.
  2. if the intersection \(U_\alpha \cap U_\beta\) is nonempty, then the map \(h_\beta \circ h_\alpha^{-1}\) is a smooth diffeomorhpism of the form \(h_\beta \circ h_\alpha^{-1}(x, v) = (x, g_{\beta\alpha}(x)v)\) where \(g_{\beta\alpha}\) is a smooth map.

If condition 2. above does not hold, then \(\pi: E \to M\) is a fiber bundle. As an easy example, consider the product bundle of rank \(r\): \(\pi = \mathrm{pr}_1: E = M\times\mathbb R^r \to M\) where \(\mathrm{pr}_1\) is the projection onto the first factor.

A vector bundle is a trivial vector bundle of rank \(r\) if there is a smooth diffeomorphism or homeomorhpism \(h: E \to M \times \mathbb R^r\) such that $h4 commutes with the projection maps in the sense that \(\pi = \mathrm{pr}_1 \circ h\), and the restriction of $h4 to each fiber \(h_x: E_x \to \{x\}\times \mathbb R^r\) is a linear isomorphism.

This implies there is a global trivialization \(h\).

Now we can realize the tangent bundle as a vector bundle:

Example 5.3.1.2.

Let \(M\) be a smooth manifold of dimension \(n\). Then \(\pi: TM \to M\) is a smooth vector bundle of rank \(n\) over \(M\). Let \(\Phi = \{(U_\alpha, \phi_\alpha): \alpha \in I\}\) be a smooth atlas of the smooth manifold \(M\). Define local trivializations \(h_\alpha: \pi^{-1}(U_\alpha) \to U_\alpha \times \mathbb R^n\) by \(h_\alpha(p, v) = (p, \theta^{-1}_{U_\alpha, \phi_\alpha, p}(v))\), where \(p \in U_ alpha\) and \(v \in T_pM\). The transition function on nonempty intersections is \[h_\beta\circ h_\alpha^{-1}(p,u) = (p, d(\phi_\beta \circ \phi_\alpha^{-1})_{\phi_\alpha(p)}(u)). \]

Since \(p \mapsto d(\phi_\beta \circ \phi_\alpha)^{-1})_{\phi_\alpha(p)}\) is a smooth map from \(U_\alpha \cap U_\beta \to \operatorname{GL}_{n}(\mathbb R)\), this indeed gives \(TM\) the structure of a vector bundle.

A smooth section of a smooth vector bundle \(\pi: E\to M\) is a smooth map \(s: M \to E\) such that \(\pi\circ s = \operatorname{id}_M\).

Now \(\pi\) is trivial iff (say it has rank \(r\)) there are smooth sections \(s_1, \ldots, s_r\) of \(\pi\) such that for each \(x \in M\), \(\{s_1(x), \ldots, s_r(x)\}\) forms a basis of \(E_x\), the fiber at \(x\).

A smooth vector field is a smooth section of \(TM\).

Derivations

Recall that the behavior of functions at germs (i.e. there is a small open neighborhood in the intersections of both domains such that the functions have the same behavior) is an equivalence relation of smooth functions. The set \(C^\infty_p(M)\) of germs has a ring structure. In fact there is a surjective map from \(C^\infty(M) \to C^\infty_p(M)\).

A derivation on \(C^\infty_p(M)\) is an \(\mathbb R\)-linear map \(\delta: C^\infty_p(M) \to \mathbb{R}\) such that it satisfies the Leibniz rule for all functions \(f, g\): \(\delta(fg) = \delta(f)g + f\delta(g)\).

Lemma 5.3.2.1.

If \(\delta\) is a derivation on \(C^\infty_0(\mathbb R^n)\), then we can write \[ \delta = \sum_{i=1}^n a_i \frac{\partial}{\partial x_i}(0), \] where \(a_i = \delta(x_i)\).

Now let \(D_pM\) be the space of derivations on \(C_p^\infty(M)\). There is an isomorphism \(T_pM \xrightarrow{\sim} D_pM\) given by \[ [(U, \phi, \vec{u})] \mapsto \sum_{i=1}^n u_i \frac{\partial}{\partial x_i}(p), \] where we have defined \(\frac{\partial}{\partial x_i}(p): C^\infty_p(M) \to \mathbb R\) by \(f \mapsto \frac{\partial(f \circ \phi^{-1})}{\partial x_i}(\phi(p))\)1

Now we can write tangent vectors as derivations. Now suppose we have \((U, \phi)\) a coordinate chart for \(M\) and have \(\phi = (x_1, \ldots, x_n)\). Now we have \(\tilde phi: TU \to \phi(U) \times \mathbb R^n\) by \(\tilde \phi(p, v) = (\phi(p), \theta^{-1}_{U, \phi, p}(v))\), and now we can write \[ \theta_{U, \phi, p}(u) \mapsto \sum_{i=1}^n u_i\frac{\partial}{\partial x_i}(p). \] Then we have \(\tilde \phi^{-1}: \phi(U) \times \mathbb R^n \to TU\) by $^{-1}(x, u) =(^{-1}(x), _{i=1}^n u_i (p) ). $$

Then locally we have smooth sections \(\frac{\partial}{\partial x_i}: U \to TU\) where \(p \mapsto (p, \frac{\partial}{\partial x_i}(p))\) of the vector bundle \(TU \to U\). At each \(p\) the evaluation at \(p\) also forms a basis for \(T_pU\), so we have a smooth frame for \(TU \to U\): an ordered basis for the fiber at each \(p\).

Now we write \(C^\infty(TU, U)\) for the smooth sections of \(TU \to U\). There is an isomorphism thus \[ T_pM = \bigoplus_{i=1}^n\mathbb R \frac{\partial}{\partial x_i}(p). \] Locally we have \[ C^\infty(U, TU) = \bigoplus_{i=1}^n C^\infty(U)\frac{\partial}{\partial x_i}. \]

Subbundles

Let \(E\) be a smooth vector bundle of rank \(r\). \(F \subseteq E\) is a smooth subbundle of rank \(k\) is we have a local trivialization \(h: \pi^{-1}(U) \to U\times \mathbb R^r\) where \(h(F\cap\pi^{-1}(U)) = U \cap (\mathbb R^k \times \{0\})\) for some open neighborhood \(U\) for all \(p \in M\).

The map \(\pi|_F: F \to M\) is a smooth vector bundle of rank \(k\), where the transition functions are the restriction of those for \(E\). We denote the fiber at \(p\) by \(F_p = E_p \cap F\).

Proposition 5.3.3.1.

Say we have a collection \(\{F_p\}_p\) of \(k\)-dimensional linear subspaces \(F_p \subseteq E_p\), and let \(F = \cup_p F_p\). Then \(F\) is a smooth subbundle of \(E\) of rank \(k\) iff for \(p \in M\) we have \(U\) an open neighborhood of \(p\) and smooth sections \(s_1, \ldots, s_k\) of \(\pi: \pi^{-1}(U) = E|_U \to U\) such that for all \(q \in U\) the \(s_i(q)\) form a basis of \(F_q\).

A distribution of dimension \(k\) is a collection \(\{F_p \subset T_pM: p \in M\}\) of \(k\)-dimensional subspaces \(F_p\) such that \(F = \cup_p F_p\) is a smooth subbundle of rank \(k\) of \(TM\).

Then this is equivalent to for each \(p \in M\), there being an open neighborhood \(U\) of \(p\) and vector fields \(X_1, \ldots, X_k\) on \(U\) such that \(\{X_i(q)\}_{q \in U\}\) is a basis of \(F_q\).

Now \(C^\infty(M, F)\) is the space of smooth sections of \(F\), and this is a submodule of \(C^\infty(M, TM)\).

Definition 5.3.3.2.

Let \(F\) be a smooth \(k\)-distribution on \(M\) an \(n\)-manifold.

  1. \(F\) is involutive if \(C^\infty(M, F)\) is a Lie subalgebra of \(C^\infty(M, TM)\) (with the usual bracket).
  2. \(F\) is completely integrable if for each \(p \in M\) there is a chart \((U, \phi)\) for \(M4 around\)p4 such that \(\forall q \in U\) \(F_q\) is spanned by \(\{\frac{\partial}{\partial x_i}(q)\}\) where \(x_1, \ldots, x_n\) are local coordinates on \(U\).

This is equivalent to saying that for each \(p\) there is a \(k\)-dimensional submanifold \(s\) such that \(p \in S\), and for all \(q \in S\), \(T_qS = F_q\).

Theorem 5.3.3.3.

A smooth distribution \(F\) on a smooth manifold is completely integrable iff \(F\) is involutive.

Operations on vector bundles

Let \(E^*\) be the set \(\cup_p E^*_p\) for \(p \in M\). We define \(\pi^*: E^* \to M\) such that \(\pi^*(E^*_p) = \{p\}\). We can equip this with a smooth manifold structure: let \(\Gamma(M, E^*)\) be the set of maps \(\phi: M \to E^*\) such that \(\phi(x) \in E_x^*\) (\(x \in M\)). Then \(\phi\) is a smooth section of \(E^* \to M\) if for every smooth section \(s: M \to E\), \(\langle \phi, s\rangle: M \to \mathbb R\) is smooth. Equivalently given a \(C^\infty\) frame \(\{s_{\alpha_i}\}\) for \(i = 1, \ldots, r\), of \(E|_{U_\alpha}\), the dual of each \(s\) gives a \(C^\infty\) frame of \(E^*|_{U_\alpha}\). Then we can write [ (x) = _{i=1}^r a_i(x)s^*_{i}(x), x U. ] Iff the \(a_i \in C^\infty(U_\alpha)\) then \(\phi\) is a smooth section.

We have the standard vector space operations on vector bundles:

  1. \(E\oplus F\) is a vector bundle with frame \(\{e_1, \ldots, e_r, f_1, \ldots, f_s\}\).
  2. \(E\otimes F\) has frame \(\{e_i\otimes f_j\}\),
  3. \(\wedge^k E\) has frame \(\{e_{i_1}\wedge \ldots \wedge e_{i_k}\}\), where \(1\leq i_1 < \cdots < i_k \leq r\).

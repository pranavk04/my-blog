Now globally we define derivations as functions on \(C^\infty(M)\) satisfying the Leibniz rule.

Definition 5.4.0.1.

Let \(X\) be a smooth vector field on \(M\). Define \(L_X: C^\infty(M) \to C^\infty(M)\) by \((L_Xf)(p) = X(p)f\) for all \(p \in M\). This is the Lie derivative. We apply \(X(p)\) to the germ determined by \(f\) at \(p\) since \(X\) is a smooth section of \(M \to TM\).

Recall that \(X\) restricted to some neighborhood \(U\) can be written in partials of the coordinates, so we have an explicit equation \[ (Xf)(p) = \sum_{i=1}^n a_i(p)\frac{\partial}{\partial x_i}(f \circ \phi^{-1})(\phi(p)). \]

Theorem 5.4.0.2.

The assignment \(C^\infty(M, TM) \mapsto D(M)\) defined by \(X \mapsto L_X\) is a \(C^\infty(M)\)-module isomorphism.

Now we can define a bracket operation giving a Lie algebra structure on vector fields: \[ [X, Y](f) = XYf - YXf = L_XL_Yf - L_YL_Xf. \] This is also a derivation as expected: we have a Lie algebra \((C^\infty(M, TM), [-, -])\).

Recall that the pullback of a smooth function \(F: M \to N\) is defined by the induced map \(F^*: C^\infty(N) \to C^\infty(M)\) given by \(f \mapsto f \circ F\). Then at a point \(p \in M\) the pullback is the map \(F_p^*: C^\infty_{F(p)}(N) \to C^\infty_p(M)\) defined by \([(V, f)] \mapsto [(F^{-1}(V), f \circ F)]\).

For each point \(p \in M\), the map \(dF_p: D_pM \to D_{F(p)}N\) is given by \[ dF_p(X)f = X(F^* f), \] for \(X \in T_pM\) a vector field and \(f \in C^\infty_{F(p)}(N)\). We can show this using local coordinates. But now this gives us a workable definition of the differential of \(F\) at \(p\).

Integral curves

Recall that a smooth curve in \(M\) is a smooth map \(\gamma: (a, b) \to M\) where \(-\infty \leq a < b \leq \infty\). For a smooth curve \(\gamma: (-\varepsilon, \varepsilon) \to M\) with \(\gamma(0) = p\), we have \(\gamma'(0)\) a derivation such that \[ \gamma'(0)f = \frac{d}{dt}(f \circ \gamma)|_{t = 0}. \]

Now if \(\gamma: I \to M\) is a smooth curve where for all \(t \in I\) we have \(\gamma'(t) = X(\gamma(t))\) for some smooth vector field \(X \in \mathfrak{X}(M)\), then \(\gamma\) is an integral curve.

Theorem 5.4.1.1.

Let \(X \in \mathfrak{X}(M)\).

  1. For any \(p \in M\) there is an open interval \(I_p \subset \mathbb R\) containing 0 such that there is an integral curve \(\phi_p: I_p \to M\) of \(X\) where \(\phi_p(0) = p\) and \(I_p\) is a maximal interval for such a \(\phi_p\). This is unique in the sense that if \(\gamma: I' \to M\) has \(\gamma(0) = p\), then \(I' \subset I_p\), and \(\gamma = \phi_p|_{I'}\).
  2. For any \(p \in M\) there is an open neighborhood \(p \in U \subset M\), open interval \(0 \in I \subset \mathbb R\), and a smooth map \(\phi: I \times U \to M\) such that \[ \begin{cases} \frac{\partial \phi}{\partial t} = X(\phi(t, q)) \\ \phi(0, q) = q. \end{cases} \]

This follows from existence and uniqueness of ordinary differential equations (as do many results for integral curves, since they are just ODEs).

By linearity we note that \(q = \phi_p(t_0) \Longrightarrow \phi_q(t) = \phi_p(t + t_0)\).

Flow

Now fix \(t\) and vary \(p\). We have \(\phi_t: U \to M\) by \(\phi_t(q) = \phi(t, q)\). This \(\phi_t\) is the local flow of \(X\). There is a global flow \(\phi_t: M \to M\) existing for all \(t \in \mathbb R\): a smooth map \(\phi: \mathbb R \times M \to M\) such that \[ \frac{\partial \phi}{\partial t}(t, q) = X(\phi(t, q)), \] where \(\phi(0, q) = q\).

Now we extend the Lie derivative to a map on \(C^\infty(M, TM) \to C^\infty(M, TM)\) by defining \(L_X(Y) = [X, Y]\). This satisfies the Leibniz rule \(L_X(fY) = L_X(f) Y + f(L_X(Y))\), for any smooth \(f\) and vector fields \(Y\) on \(M\).

\(L_X\) is \(C^\infty(M)\)-linear in \(X\) on \(C^\infty(M)\), but it is not on \(C^\infty(M, TM)\): it is only \(\mathbb R\)-linear in this case.

The pushforward of a smooth diffeomorphism \(F: M \to N\) on a smooth vector field \(X\) is defined as \[ F_*X(p) = (dF)_{F^{-1}(p)}(X(F^{-1}(p))). \] The pullback given a smooth vector field \(Y\) on \(N\) is \(F^*Y = (F^{-1})_*(Y)\), which is a smooth vector field on \(M\).

We have some important properties of flow:

Proposition 5.4.2.1.

Fix a point \(p \in M\). There is an open neighborhood \(U\) of \(p\) in \(M\) and a local flow \(\phi_t: U \to M\) of a vector field \(X\) for \(t\) in some neighborhood \((-\varepsilon, \varepsilon)\) of 0. Then we have

  1. For each \(f \in C^\infty_p(M)\), we have \[ (L_Xf)(p) = \frac{d}{dt}|_{t=0}(\phi^*_tf)(p) = \frac{d}{dt}|_{t=0}(f \circ \phi_t)(p). \]
  2. For a smooth vector field \(Y\) defined on an open neighborhood \(V\) of \(p\) in \(U\), we have \[ (L_XY)(p) = -\frac{d}{dt}|_{t=0} ((\phi_t)_*Y)(p) = \lim_{t \to 0} \frac{Y(p) - ((\phi_t)_*Y)(p)}{t}. \]

We also have for some small positive number \(\delta\) that for an open subset \(U \subset M\), and a function \(h: (-\delta, \delta) \times U \to \mathbb R\) smooth such that \(h(0, q) = 0\) for all \(q \in U\), that \(h(t, q) = tg(t, q)\) for some smooth \(g: (-\delta, \delta) \times U \to \mathbb R\).

Cotangent spaces

The cotangent space at \(p \in M\) is \(T^*_pM = (T_pM)^*\) as a dual vector space. The cotangent bundle is the dual of the tangent bundle.

Definition 5.5.1.1.
  1. A smooth \((r, s)\)-tensor on \(M\) is a smooth section of \[ T_s^rM = (TM)^{\otimes r} \otimes (T^*M)^{\otimes s}. \]
  2. A smooth \(s\)-form is a smooth section of \(\wedge^s T^* M\).

A vector field is thus a \((1, 0)\)-tensor, and an \(s\)-form is a particular kind of \((0, s)\)-tensor. A 1-form is a \((0, 1)\)-tensor.

Recall that \(f: M \to \mathbb R\), if smooth, has a differential at \(p\) \(df_p: T_pM \to \mathbb R\), so then \(df_p \in T^*_pM\). If \((U, \phi)\) is a chart for \(M\), and let \(x_i\) be local coordinates, then \[ \langle df, \frac{\partial}{\partial x_i} \rangle = \frac{\partial f}{\partial x_i} \] are smooth functions on \(U\), so \(df\) is a smooth section of \(T^*M\): it is a smooth 1-form.

We know that the partial derivatives of the local coordinates are a smooth frame for \(TU\). The differntials \(dx_i\) of the coordinate functions are smooth sections of \(T^*U\) and we have that \[ dx_i\left (\frac{\partial}{\partial x_j}\right ) = \delta_{ij}. \]

So then the dual frame is \(\{dx_1, \ldots, dx_n\}\) for \(T^*U\). For any smooth \(f\) we can write \[ df = \sum_{i=1}^n \frac{\partial f}{\partial x_i}dx_i. \]

We can also do this for any smooth \((r, s)\)-tensor: \[ \sum a^{i_1, \ldots, i_r}_{j_1, \ldots, j_s} \frac{\partial}{\partial x_{i_1}} \otimes \cdots \otimes \frac{\partial}{\partial x_{i_r}} \otimes dx_{j_1} \otimes \cdots \otimes dx_{j_s}. \]

Here the sum is taken over \(i_{k}\) and \(j_{l}\) lying in between 1 and \(n\), like expected. The \(a\)’s are smooth functions.

Now let \(\phi: M \to N\) be a smooth map between smooth manifolds. Let \(p \in M\), such that \(d\phi_p\) is a linear map. Then there is a dual liner map \(d\phi_p^*: T^*_{\phi(p)}N \to T^*_pM\), so that for any \(s\)-tensor \(T\) on \(N\), we let \(\phi^*T\) denote the \(s\)-tensor of \(M\): \[ \phi^*T(p) = (d\phi^*_p)^{\otimes s}(T(\phi(p))). \]

Definition 5.5.1.2.

Let \(\Omega^s(N)\) denote the space of smooth \(s\)-forms on \(N\) (smooth sections of \(\wedge^s T^*N\)).

For any \(f: N \to \mathbb R\), we have \(\phi^*(df) = d(\phi^*f)\).

Pullback and pushfoward of tensors

We fix a smooth diffeomorhpism \(\phi: M\to N\). We know that \(d\phi_p: T_pM \to T_{\phi(p)}N\) is an invertible linear map with inverse \(d(\phi^{-1})_{\phi(p)}\). We get a map \(\phi^*: C^\infty(N, T^r_sN) \to C^\infty(M, T^r_sM)\) that is the pullback defined by \[ phi^*T(p) = [d(\phi^{-1})_{\phi(p)})^{\otimes r} \otimes (d\phi^*_p)^{\otimes s}]T(\phi(p)). \]

The map \(\phi_*: C^\infty(M, T^r_sM) \to C^\infty(N, T^r_sN)\) defined by \(\phi_* = (\phi^{-1})^*\) is the pushfoward of \(\phi\).

Tangent spaces

Let \(M\) be a smooth manifold. Let \((U, \phi)\) and \((V, \psi)\) be two charts for \(M\) around \(p \in M\). THen for vectors \(\vec{u}, \vec{v} \in \mathbb R^n\), let us write \((U, \phi, \vec{u}) \sim_p (V, \psi, \vec{v})\) if \[ d(\psi \circ \phi^{-1})_{\phi(p)}(\vec{u}) = \vec{v}. \]

This is an equivalence relation, and let the tangent space to \(M\) and \(p\) be defined as \[ T_pM = \{[U, \phi, \vec{u}]\}\] where \((U, \phi)\) is a chart around \(p\), and \(\vec{u} \in \mathbb R^n\).

Let us define a map \(\theta_{U, \phi, p}: \mathbb R^n \to T_pM\) by \(\theta(\vec{u}) = [(U, \phi, \vec{u})].\) This is a bijection, which gives \(T_pM\) an \(\mathbb R\)-linear structure, independent of the choice of chart.

A tangent vector at \(p\) is a vector in the \(n\)-dimensional real vector space \(T_pM\).

Tangent bundle

Define as a set \[ TM = \{(p, v): p \in M, v \in T_pM\}. \] By mapping \((p, v) \mapsto p\) we get a surjection \(TM \to M\). Let \((U, \phi)\) be a chart for \(M\). define \(\tilde \phi: \pi^{-1}(U) \to \phi(U) \times \mathbb R^n\) as the map \(\tilde \phi(p, v) = (\phi(p), \theta_{U, \phi, p}^{-1}(\vec{v}))\). Now we give \(TM\) the topology such that \(\tilde \phi\) is a homeomorhpism for each chart \((U, \phi)\). Then \(A \subset TM\) is open if and only if for each chart \((U, \phi)\) for \(M\), the set \(\tilde \phi(\pi^{-1}(U) \cap A)\) is open in \(\phi(U)\times \mathbb R^n\).

Then \(TM\) has a topological manifold structure. We can identify in fact \(\pi^{-1}(U)\) with \(TU\) for \(U\) open in \(M\). Then we have \(\pi^{-1}*(U) \cap \pi^{-1}(V) =- TU \cap TV = T(U \cap V)\), which is \(\pi^{-1}(U \cap V)\). Then transition function for two charts is given by \[ \tilde \psi \circ \tilde \phi^{-1}: \tilde \phi(TU \cap TV) \to \tilde \psi(T(U \cap V))\] where \[ \tilde \psi \circ \tilde \phi^{-1}(x, u) = (\psi \circ \phi^{-1})(x), d(\psi \circ \phi^{-1}_x(u))\].

If we only work on \(C^k\) manifolds, then \(TM\) is a \(C^{k-1}\) manifold1. The map \(\pi: TM \to M\) is a smooth submersion for a smooth manifold \(M\).

Differentials of maps

If \(f: M \to N\) is a smooth map between smooth manifolds of dimension \(m\) and \(n\), then the differential of \(f\) at \(p\) is the linear map \(df_p: T_pM \to T_{f(p)}N\) where: given a chart \((U, \phi)\) for \(M\) around \(P\) and a chart \((V, \psi)\) for \(N\) around \(f(p)\), where \(f(U) \subset V\), then let \(g = \psi \circ f \circ \phi^{-1}: \phi(U)\to \psi(V)\). Let \(df_p\) then be \[ df_p = \theta_{V, \psi, f(p)}\circ dg_{\phi(p)}\circ \theta_{U, \phi, p}^{-1}. \]

Theorem 5.2.3.1.

Let \(f: M_1 \to M_2\), \(g: M_2 \to M_3\) be smooth maps between smooth manifolds. Then

  1. The composition \(g\circ f: M_1 \to M_3\) is a smooth map.
  2. For each \(p \in M_1\), the differential of the compositon is given by \(d(g\circ f)_p = dg_{f(p)}\circ df_p\).

Note that now we can say \(f\) is a submersion or immersion based on the surjectivity and injectivity of \(df_p\).

Now we also have:

Remark 5.2.3.2.

If \(f: M \to N\) is a smooth map, and \(q \in N\) is a regular value, \(S = f^{-1}(q)\) is a submanifold of \(M\) of dimension \(m - n\). For each \(p \in S\), the tangent space \(T_pS\) is given by \(\ker{df_p}\). There is a short exact sequence \(0 \to T_pS \to T_pM\to T_qN\to 0\).

Note that \(T_p\mathbb R^n \cong \mathbb R^n\).

Now we define for \(f: M \to N\) the differential \(df: TM \to TN\) as a smooth2 map where \[ df(p, v) = (f(p), df_p(v)).\]

Lemma 5.2.3.3.

If \(M\) is a smooth submanifold of \(N\) of dimension \(m\), then \(TM\) is a smooth submanifold of \(TN\) of dimension \(2m\).

  1. but note that \(TM\) is still a \(C^\infty\) manifold if \(M\) is \(C^\infty\).↩︎

  2. or \(C^{k-1}\) if \(k \neq \infty\)↩︎
